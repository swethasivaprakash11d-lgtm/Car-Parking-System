# Smart Car Parking System using Arduino UNO

## Overview

This project implements a Smart Car Parking System using Arduino UNO and ultrasonic sensors. The system detects the presence of vehicles in parking spaces and indicates whether slots are available or occupied.

## Components Used

* Arduino UNO
* Ultrasonic Sensor (HC-SR04)
* LEDs (Red and Green)
* Breadboard
* Jumper Wires
* USB Cable
* LCD Display (if used)

## Working Principle

The ultrasonic sensor measures the distance between the sensor and nearby objects. When a vehicle enters a parking slot, the measured distance changes. The Arduino processes this information and determines whether the slot is occupied or available. The status is displayed using LEDs, an LCD display, or the Serial Monitor.
